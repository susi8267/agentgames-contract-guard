Contract Guard

Read-only BSC contract risk triage. Paste a BSC contract address before a mint/buy and get an explained verdict built only from public read-only checks: bytecode presence (eth_getCode), Sourcify source verification, and owner() / paused() probes. No keys, no signing, no writes. This is a triage heuristic, not an audit.

Endpoints: GET /health · POST /check {"address":"0x…"}

Result will appear here.
